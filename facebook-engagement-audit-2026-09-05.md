- “Shares” is Facebook's displayed share counter on the source Reel. Because each campaign was distributed to groups by the same account, it includes campaign distribution and is not a clean organic-engagement metric.
- Facebook's current interface did not expose reach, impressions, plays/views, or a numeric reaction count for these posts.
- A permalink can still be pending admin approval; status was determined from the message shown inside each post, not from URL shape alone.
- Group membership totals overlap heavily and must not be reported as unique reach.
